# Import a generated .litematic (Java Edition)

After you download a schematic from [Minecraft Schematic Generator](https://minecraftschematicgenerator.com), Litematica loads it from `.minecraft/schematics`.

Follow the live [import guide](https://minecraftschematicgenerator.com/import) for Fabric, CurseForge, and Modrinth. Java Edition only — not Bedrock.

Also: [what is a litematic](https://minecraftschematicgenerator.com/what-is-a-litematic).
